# Synology AMDGPU Top 0.1.4

Package Center showed Intel GPU Top and AMDGPU Top with identical green graph icons, making it harder to choose the package for the installed GPU. AMDGPU Top 0.1.4 uses a red graph icon, distinct from the blue Intel GPU Top icon.

This is an icon and package metadata update. The AMD `amdgpu_top` executable and v0.1.3 runtime are unchanged; downstream packages pinned to that runtime do not need rebuilding.

The SPK passed package structure and embedded-icon checks. It has not been reinstalled on DSM hardware as part of this icon-only release.

SPK SHA-256: `f5ca3b9144e03d60bdb3463f2139189bf65b08b6134aaa9e34e8fb716f9174ae`

## 한국어

Package Center에서 Intel GPU Top과 AMDGPU Top 아이콘이 같은 초록색 그래프로 표시되어 GPU에 맞는 패키지를 고르기 어려웠습니다. AMDGPU Top 0.1.4에는 빨간색 그래프 아이콘을 적용해 파란색 Intel GPU Top 아이콘과 구분했습니다.

이번 변경은 아이콘과 패키지 메타데이터에 한정됩니다. AMD `amdgpu_top` 실행 파일과 v0.1.3 런타임은 그대로이며, 해당 런타임을 고정해 사용하는 파생 패키지는 다시 빌드할 필요가 없습니다.

SPK 구조와 내장 아이콘을 검사했습니다. 아이콘만 바꾼 릴리즈이므로 DSM 실기 재설치는 진행하지 않았습니다.
